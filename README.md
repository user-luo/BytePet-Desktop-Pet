# 🐱 BytePet 电子宠物

一个基于 Python + PyQt5 的 Windows 桌面电子宠物。打开程序给宠物取名后，一只透明背景的小猫会常驻在你的桌面右下角，会做各种动作、提醒你喝水休息、还会调皮地玩弄桌面图标——但当你专注办公或玩游戏时，它会乖乖安静下来，绝不打扰。

## ✨ 功能一览（对应需求）

| 模块 | 说明 |
|------|------|
| 🏷 **取名启动** | 启动对话框输入名字（限汉字/数字/字母，默认"一一"）；🎲 骰子随机名（大白/一一/苗苗/小花花）；性别 MM(女)/DD(男) 默认 MM |
| 🐾 **多开支持** | 可同时开多个不同名字的宠物；**同名宠物只能开一个**（Windows 命名互斥锁） |
| 🖼 **透明置顶** | 无边框透明窗口常驻最顶层；左键拖动移动；右下角手柄 / 滚轮调节大小 |
| 💬 **聊天气泡** | 圆角气泡 + 小尾巴，淡入淡出，自动定位在宠物头顶，消息排队 |
| ⚙ **设置菜单**（托盘右键） | 开机启动 · 温馨提醒 · 置顶显示 · 模式选择 · 代办事项 · 采集桌面图标 · 基础信息 · 退出 |
| 🔔 **温馨提醒** | 每 45 分钟气泡提醒伸懒腰 / 喝水 / 放松眼睛，并触发喝水动作 |
| 📋 **代办事项** | 日期(默认当天) + 时间(默认此时) + 自定义内容，到点气泡提醒；可标记完成 / 删除 |
| 🎭 **三种模式** | 综合模式(默认) / 文静模式 / 调皮模式，3 选 1 |
| 😴 **文静动作** | 舔爪子、舔毛、睡觉、打哈欠、比爱心、抛媚眼、呼呼大睡、四脚朝天翻肚皮 |
| 😼 **调皮动作** | 玩弄桌面图标、桌面跳来跳去、蹭鼠标、桌面跳动、抓裂图标、巡视领地 |
| 🖥 **桌面图标采集** | 获取桌面所有图标及名字，转为透明 PNG 保存到本地，作为玩耍素材 |
| 🧠 **办公智能检测** | 检测前台窗口：游戏 / 全屏 / WPS / Word / Excel / PPT / PS / 企业微信等办公软件时，宠物**只做文静动作与喝水/事务提醒**，绝不调皮捣蛋 |
| 💾 **本地数据库** | SQLite 存储：基础信息表（ID/名称/性别/创建日期/年龄天数）、代办事务表、运行动作日志表 |
| 📊 **基础信息窗口** | 显示宠物编号、名称、性别、创建日期、年龄（天）、当前模式、代办数 |

## 🚀 快速开始

### 方式一：直接运行打包好的 exe
双击 `dist\BytePet\BytePet.exe` → 取名 → 开始养育。
（多开：复制 exe 或再次双击，输入不同名字即可）

### 方式二：开发模式运行
```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 处理猫素材（首次，需联网下载 AI 模型；后续跳过）
python tools/process_assets.py

# 3. 运行
python main.py                 # 弹出取名对话框
python main.py --name 大白     # 指定名字启动（多开 / 开机自启用）
```

## 📦 打包成 exe
```bash
pip install pyinstaller
build_exe.bat
# 产物：dist\BytePet\BytePet.exe
```

## 🛠 技术栈
- **GUI**：PyQt5（透明置顶无边框窗口、系统托盘、自绘气泡与动画）
- **抠图**：rembg + onnxruntime（u2net 模型，保留猫的毛发/眼睛/爪子细节，仅移除背景）
- **系统集成**：pywin32（桌面图标枚举、活跃窗口检测、命名互斥锁、注册表开机启动）
- **数据**：SQLite（Python 标准库 sqlite3）
- **打包**：PyInstaller

## 💡 设计要点
- **素材处理**：原始猫照片为写实室内场景（非透明），通过 AI 抠图去背景并裁剪到内容边界，得到可叠加于桌面的透明素材，对应需求「图片转换保留猫猫关键细节」。
- **不打扰办公**：`activity.py` 每 5 秒检测前台窗口的进程名/标题/全屏状态，命中办公或游戏时，宠物动作池自动收敛为文静动作。
- **多开互斥**：每个宠物名对应一个 Windows 命名互斥量 `Local\BytePet_Pet_<名字>`，第二次以同名启动即被拒绝。
- **年龄计算**：基于创建日期动态计算（今天 − 创建日），每日自然增长。

## 📌 说明
- 开机自启动写入注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\BytePet`。
- 数据库 / 配置 / 日志 / 采集图标均存于 exe 所在目录的 `data\` 下，便于携带。
